### Визуальный дизайн

#### Цветовая схема:
- **HUD**: Тёмный фон (RGB 30,30,30) + золотая рамка
- **Shop**: Золотая тема (RGB 255,200,0)
- **Zones**: Синяя тема (RGB 100,150,255)
- **Rebirth**: Фиолетовая тема (RGB 200,100,255)
- **Daily**: Зелёная тема (RGB 150,255,150)

#### UI элементы:
- Закруглённые углы (UICorner)
- Плавные переходы
- Цветовая индикация состояний:
  - Зелёный = доступно/разблокировано
  - Красный = недоступно/заблокировано
  - Серый = неактивно
  - Золотой = монеты
  - Голубой = гемы

### Функциональность

#### Автоматические обновления:
- HUD обновляется при каждом изменении данных
- Shop показывает актуальные цены и уровни
- Zones отображают статус разблокировки
- Rebirth проверяет возможность перерождения

#### Интерактивность:
- Клик по мобу = атака + визуальный урон
- Клик по улучшению = покупка (если хватает монет)
- Клик по зоне = телепортация (если разблокирована)
- Hover эффекты на всех кнопках

#### Анимации:
- Level Up: масштабирование + движение + fade out
- Damage Numbers: полёт вверх + fade out
- Critical Hits: увеличенный размер + красный цвет
